MyTranslator User Guide

Build {{BUILD_NUMBER}} · Offline translation and text improvement on macOS

Quick start

  1. Open Settings and choose a Primary language and an Other language.
  2. Select text in any app, then press Control + Shift + T to translate it or Control + Shift + P to improve its wording. These are the initial shortcuts; you can change them in Settings.
  3. When the selected text is editable, MyTranslator replaces the selection. For read-only text, it shows the result in a separate window with Listen, Copy, and Close buttons.

MyTranslator needs macOS Accessibility permission to read the selection and replace editable text. Grant it in System Settings → Privacy & Security → Accessibility.

Languages and interface

The Primary language is the usual translation destination. If the selected text is already in that language, MyTranslator translates it into the Other language. The app's windows, menus, buttons, tooltips, and app messages use the saved Primary language. The guide stays in English and is available from the app's Help menu.

The two language lists show the 22 distinct languages supported by Apple Translation on this Mac. Regional variants are grouped, including Chinese as one entry. The languages are Arabic, Chinese, Danish, Dutch, English, French, German, Hindi, Indonesian, Italian, Japanese, Korean, Norwegian Bokmål, Polish, Portuguese, Russian, Spanish, Swedish, Thai, Turkish, Ukrainian, and Vietnamese.

Some languages still need an offline pack. The Languages information panel explains this requirement. Open Apple's Translate app and download a language before using it in MyTranslator, then reopen Settings. On this Mac, Arabic, Hindi, Indonesian, Polish, Russian, Thai, and Ukrainian currently need a download. The actual installed packs can change over time.

Settings

Choose the two languages, record the Improve and Translate shortcuts by clicking their fields, and set the maximum wait time (3–300 seconds). Click Save to apply the changes immediately. Click Cancel to leave them unchanged. The information button beside Languages explains how to download offline language packs.

The main window has three compact buttons, from left to right: Settings, Quit, and Hide. Hide minimizes the window while MyTranslator continues running; reopen it from the Dock. Quit ends the app completely, just like Quit MyTranslator in the app menu. Closing a window keeps the app running. In Settings, Save applies changes and Cancel discards them.

Choose About MyTranslator from the app menu to see the build number followed by the date of the most recent build in parentheses. The date uses the saved Primary language.

Results and privacy

The result window lets you listen to a result, copy all its text, or close the window. The app shows progress by changing its Dock icon while it works. Translation uses Apple's local Translation framework and downloaded languages. Improve uses Apple Foundation Models on supported Macs. The selected text is processed on the Mac by these system frameworks.

Troubleshooting

  • A shortcut does nothing: check Accessibility permission and make sure another app or macOS has not taken the same shortcut. Change it in Settings if needed.
  • A language is missing: download it in Apple's Translate app, then reopen Settings.
  • Translation times out: try again or increase the maximum wait time in Settings.
  • Improve is unavailable: check that Apple Foundation Models is available on this Mac.
  • A result was not inserted: select editable text. Read-only selections display a result window instead. The app also avoids replacing a selection when an improvement changes the original language.

Reliable translation and replacement

The translation timeout includes sending the selected text to the local translator, waiting for its result, and collecting output. A stalled translator is stopped so another operation can be attempted.

Automatic replacement requires the original app, focused text element, selection position and selected text to remain unchanged. If you switch windows, change the selection, or the app does not expose a verifiable selection, MyTranslator shows the result window instead. Copy the result there and paste it where needed.

Rebuilding prepares and verifies a separate bundle before replacing the app. If compilation or signing fails, the previous app remains available.
